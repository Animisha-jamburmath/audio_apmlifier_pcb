# TPA3116D2 Stereo Audio Amplifier

## Overview
A custom stereo audio amplifier PCB designed using the TPA3116D2 Class-D amplifier IC.

## Design Tools
- KiCad 9.0
- Schematic capture
- PCB layout and 3D visualization

## Project Features
- Stereo audio output
- TPA3116D2 Class-D amplifier
- 12 V intended power supply
- LC output filtering
- Custom PCB layout

## Project Status
Schematic and initial PCB layout completed.

Hardware fabrication, assembly and performance testing are pending.

## Future Work
- Electrical and PCB design validation
- PCB fabrication
- Component assembly
- Audio performance testing
- Thermal testing
